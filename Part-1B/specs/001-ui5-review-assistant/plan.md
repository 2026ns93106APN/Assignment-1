# Implementation Plan: UI5 Code Review Assistant

**Branch**: `001-ui5-review-assistant` | **Date**: 2026-11-13 | **Spec**: specs/001-ui5-review-assistant/spec.md

**Input**: Feature specification from `/specs/001-ui5-review-assistant/spec.md`

## Summary

ui5-review-assistant is a Node.js ES-module command-line tool that analyzes a single UI5 controller (`.js`) or XML view file using the Gemini API and returns structured review findings in a fixed JSON schema. It checks hardcoded user-visible text requiring i18n and missing error handling, isolating service/model errors and evaluating accuracy against a 18-case synthetic dataset.

## Technical Context

**Language/Version**: Node.js (ES modules)

**Primary Dependencies**: `@google/genai` (or Google Gen AI SDK), `dotenv`, `eslint` (flat config) with `eslint-plugin-security`

**Storage**: File system (`.env`, input UI5 files, `evidence/` results)

**Testing**: Node built-in test runner (`node:test`), running against stored model outputs during ordinary test suite

**Target Platform**: Node.js runtime (Linux / cross-platform)

**Project Type**: CLI tool & evaluation harness

**Performance Goals**: Hermetic evaluation suite execution; reliable API error isolation and fallback reporting

**Constraints**: API key loaded via dotenv, never logged or printed; strict adherence to zero ESLint security warnings/errors; fixed evaluation threshold (macro F1 ≥ 0.70)

**Scale/Scope**: Single file review workflow; 18 synthetic evaluation cases
